# دریافت و نصب

## محیط‌های دارای پوشه اسکیل

مخزن را با حساب دارای دسترسی دریافت کنید:

```bash
git clone https://github.com/piwoinjast/NobiWriter.git
cd NobiWriter
```

پوشه کامل `skills/nobiwriter` را در محل اسکیل‌های محیط مقصد کپی کنید. فایل `SKILL.md` و پوشه‌های `references` و `templates` باید کنار هم باقی بمانند. مسیر مقصد را از تنظیمات همان محیط تعیین کنید.

برای محیط‌های Codex که از مسیر کاربری پیش‌فرض استفاده می‌کنند:

```bash
mkdir -p "${CODEX_HOME:-$HOME/.codex}/skills"
cp -R skills/nobiwriter "${CODEX_HOME:-$HOME/.codex}/skills/"
```

اگر پوشه‌ای با همین نام وجود دارد، پیش از جایگزینی، تغییرات شخصی آن را حفظ کنید. بارگذاری مجدد اسکیل‌ها تابع محیط میزبان است.

## محیط‌های بدون پشتیبانی اسکیل

محتوای `SKILL.md` را به‌عنوان دستور و منابع مرتبط را به‌عنوان فایل مرجع ارائه کنید. صرف بارگذاری فایل‌ها تضمین نمی‌کند محیط، مسیریابی اسکیل را اجرا کند. در درخواست، خواندن مرجع مرتبط را مشخص کنید.

## ساخت بسته قابل انتقال

از ریشه مخزن اجرا کنید:

```bash
python -m pip install -r requirements-dev.txt
python scripts/package_skill.py
```

بسته `dist/nobiwriter-1.1.1.zip` فقط فایل‌های لازم برای اجرای اسکیل را دارد. راهنماهای توسعه و سناریوهای ارزیابی داخل این فایل قرار نمی‌گیرند. امکان نصب مستقیم فایل ZIP به محیطی که استفاده می‌کنید بستگی دارد.

## بررسی دسترسی

پس از نصب، یک درخواست درباره برداشت با نتیجه نامعلوم اجرا کنید. پاسخ باید نامعلوم بودن وضعیت را حفظ کند و نتیجه یا اقدام تاییدنشده نسازد. این بررسی کوتاه جای [ارزیابی کامل](../evals/README.md) را نمی‌گیرد.

## به‌روزرسانی

در نسخه دریافت‌شده از Git، ابتدا تغییرات محلی را ثبت یا حفظ کنید و سپس `git pull --ff-only` اجرا کنید. اگر شاخه‌ها واگرا شده‌اند، ادغام باید جداگانه انجام شود. نسخه جدید بسته را جایگزین نسخه قبلی کنید.

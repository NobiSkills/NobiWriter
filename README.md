# نوبی‌رایتر (NobiWriter) | نظام نوشتن، پیام‌رسانی و کنترل ادعای نوبیتکس
**نسخه:** ۱.۰ | **وضعیت:** مخزن داخلی نوبیتکس (Private Repository)

نوبی‌رایتر مرجع جامع تحلیل، پیام‌رسانی، نوشتار تجربه کاربری (UX Writing) و کپی‌رایتینگ نوبیتکس است. هدف این پروژه تبدیل دانش برند، شناخت مخاطب، واقعیت محصول و اصول نوشتن به تصمیم‌های قابل تکرار برای تمام تیم‌های نوبیتکس است.

> **گزاره مرکزی:** نوبی‌رایتر باید به فهم و اختیار کاربر کمک کند و فاصله میان ارزش واقعی محصول و ادراک او را کاهش دهد. هویت مطلوب برند **«نوآور در راهکار، قابل‌اتکا در رفتار» (Innovative & Dependable)** است.

## ساختار مخزن (Repository Structure)

- `SKILL.md`: هسته مرکزی اسکیل و قواعد الزام‌آور (System Prompt)
- `CHANGELOG.md`: تاریخچه تغییرات نسخه‌ها
- `references/ux-and-microcopy-patterns.md`: اصول UX و ۴۰ الگوی استاندارد (P01-P40)
- `references/copywriting-and-landings.md`: چارچوب خلاقیت، شعار، هیرو، لندینگ و اطلاعیه‌ها
- `references/products-and-vocabulary.md`: واژه‌نامه کنترل‌شده و قواعد ۱۶ خانواده محصول
- `references/claims-and-evaluation.md`: نظام ادعا/شاهد (C001-C100) و ۶۰ آزمون مرزی (T01-T60)
- `templates/`: قالب‌های استاندارد بریف، کارت حقیقت محصول و رکورد ادعا
- `evals/boundary-tests-T01-T60.yaml`: سناریوهای تست خودکار مرزی

# NobiWriter

نسخه اولیه چارچوب نوشتن و بازبینی فارسی نوبیتکس برای سه مسیر: نوشتار محصول و تجربه کاربری، تبلیغ و شعار، صفحات و اطلاعیه‌ها.

وضعیت: نسخه کاری 0.1.1. راهنمای رسمی مصوب سازمان نیست. صحت زبانی به معنی تأیید فنی، حقوقی یا مجوز انتشار نیست. ارزیابی رفتاری مدل هنوز انجام نشده است.

## استفاده
در محیطی که از skill folder پشتیبانی می‌کند، پوشه `skills/nobiwriter` را در محل اسکیل‌ها قرار بده. توضیحات و نقطه ورود در [SKILL.md](skills/nobiwriter/SKILL.md) هستند. در محیط‌های دیگر، این فایل و منابع مرتبط را به‌عنوان دستور و مرجع استفاده کن. اتصال GitHub به‌تنهایی اسکیل را در همه ابزارها نصب نمی‌کند.

نمونه درخواست: «با $nobiwriter هشدار برداشت را برای وضعیت نامعلوم بنویس. وضعیت کسر مبلغ معلوم نیست و امکان تکرار درخواست تأیید نشده است.»

## وضعیت منابع
قواعد اجرایی از منابع پروژه استخراج و تعارض‌های شناخته‌شده اصلاح شده‌اند. متن کامل کتاب، گزارش‌های محرمانه و PDFهای پژوهش در این مخزن قرار ندارد. [نقشه منابع](skills/nobiwriter/references/source-map.md) و [فهرست دسترسی](docs/source-inventory.json) حدود استفاده را ثبت می‌کنند.
فایل‌های S04-normalized.txt و مرجع هویت برند پس از ارسال مجدد بررسی و ادغام شدند. بانک اصلی ادعاها و حقایق جاری محصولات هنوز وارد نشده‌اند. نمونه‌های آموزشی، شاهد قابلیت محصول نیستند.

## اعتبارسنجی محلی
```bash
python -m pip install -r requirements-dev.txt
python scripts/validate_repository.py
```
این بررسی صحت ساختار، لینک‌های داخلی و قرارداد داده‌ها را می‌سنجد. کیفیت یا صحت مالی خروجی مدل را تضمین نمی‌کند. آزمون رفتاری طبق [راهنمای ارزیابی](evals/README.md) جدا اجرا شود.

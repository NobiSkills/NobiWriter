# زمینه مخاطب
منشأ: پایگاه دانش داخلی پروژه، بخش‌های شناخت مخاطب و اعتماد. درصدهای تاریخی را ترکیب فعلی کاربران تلقی نکن.

برای انتخاب متن پنج محور را بررسی کن: کار مورد انتظار، سطح دانش، مرحله سفر، وضعیت اعتماد و حساسیت مالی اقدام.
| زمینه | اولویت اطلاعات |
| --- | --- |
| سرمایه‌گذاری و نگهداری | ترکیب، افق، سازوکار، هزینه و ریسک |
| معامله حرفه‌ای | نوع سفارش، اجرا، هزینه، وضعیت و کنترل ریسک |
| انتقال و پرداخت | مقصد، مقدار، شبکه، زمان و هزینه |
| تازه‌وارد | مفهوم ضروری، مرحله بعد و پیامد اقدام |
| کاربر نگران دارایی | وضعیت فعلی، اثر بر دارایی، اقدام و زمان معتبر پیگیری |
| پرایم و VIP | خدمت مشخص، شرایط اختصاصی و سطح تعهد واقعی |

پرایم و VIP را سطح خدمت بدان، نه نشانه قطعی دانش مالی. از دارایی یا قدمت حساب، تخصص استنتاج نکن. اعتماد به رمزارز، صرافی و عملیات مشخص را جدا بررسی کن. نیاز به حفظ ارزش پول را تضمین عملکرد محصول معرفی نکن.

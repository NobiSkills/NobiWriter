# تصمیم‌های طراحی
| تصمیم | دلیل |
| --- | --- |
| یک اسکیل و سه مسیر | حفظ هویت مشترک با روش اجرا و معیارهای متفاوت |
| خواندن منابع متناسب با درخواست | جلوگیری از بارگذاری همه پژوهش‌ها در هر کار |
| جداسازی قواعد از داده جاری | به‌روزرسانی هزینه و قابلیت بدون بازنویسی چارچوب |
| بانک ادعا آغازین خالی | الگوهای ادعا، مجوز نوبیتکس نیستند |
| اصلاح نمونه‌های برداشت و اعتبار | جلوگیری از اعلام وضعیت نادرست یا تضمین ضمنی |
| مجوز متن‌باز انتخاب نشده | انتخاب مجوز نباید حقوق شرکت و منابع ثالث را فرض کند |
| حفظ مخزن خصوصی | انتشار عمومی و بازنشر اسناد داخلی در این مرحله درخواست نشده است |

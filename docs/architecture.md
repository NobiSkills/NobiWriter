# ساختار نوبی‌رایتر ۱.۱.۱

نسخه قابل نصب در `skills/nobiwriter` قرار دارد. کار از `SKILL.md` شروع می‌شود و هر نوع درخواست به منبع مرتبط ارجاع داده می‌شود. راهنمای استفاده و فایل‌های توسعه بیرون از این پوشه‌اند تا همراه اسکیل بارگذاری نشوند.

| لایه | مسئولیت |
| --- | --- |
| هسته | قواعد الزام‌آور، تشخیص مسیر و شکل پاسخ |
| منابع | هویت، لحن، واژگان، محصول، خلاقیت و ادعا |
| قالب‌ها | دریافت بریف و ورودی مورد نیاز |
| مستندات و نمونه‌ها | آموزش کاربر و نگهداری پروژه |
| قراردادها و ارزیابی | بررسی ساختار داده و کیفیت خروجی |

قواعد نوشتن از اطلاعات متغیر محصول جدا نگه داشته شده‌اند. این مخزن بانک به‌روز ادعاهای مجاز نیست و مثال‌های آن نیز قابلیت‌های فعلی محصول را تایید نمی‌کنند. تاریخچه نسخه‌ها در فایل `CHANGELOG.md` قرار دارد.

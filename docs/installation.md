# دریافت و نصب

## دریافت نسخه منتشرشده از GitHub Releases

[دانلود مستقیم ZIP آخرین نسخه](https://github.com/piwoinjast/NobiWriter/releases/latest/download/nobiwriter-skill.zip) · [فهرست Releaseها](https://github.com/piwoinjast/NobiWriter/releases)

بسته با نام `nobiwriter-skill.zip` منتشر می‌شود و شامل پوشه `nobiwriter` و فایل `SKILL.md` است. لینک دریافت به انتشار Release دارای فایل بسته نیاز دارد. مخزن در بررسی 2026-10-24 عمومی است. ثبت تغییر روی شاخه اصلی به‌تنهایی فایل Release قبلی را به‌روز نمی‌کند.

برای انتشار نسخه جدید، ابتدا تغییرات را در `main` ادغام کنید. مقدار دو فایل `VERSION` باید با شماره نسخه هماهنگ باشد. سپس تگ نسخه مانند `v1.2.0` را روی کامیت تاییدشده ایجاد و به GitHub ارسال کنید. گردش‌کار `.github/workflows/release.yml` تست‌ها را اجرا می‌کند، بسته نصب را می‌سازد و آن را به GitHub Release پیوست می‌کند. امکان اجرای دستی گردش‌کار با تگ موجود نیز فراهم است. اگر Release همان تگ قبلا وجود داشته باشد، گردش‌کار آن را بازنویسی نمی‌کند.

لینک نسخه ثابت نیز به شکل `https://github.com/piwoinjast/NobiWriter/releases/download/v1.2.0/nobiwriter-skill.zip` خواهد بود. دریافت بسته جدید، نصب‌های قبلی در ChatGPT را خودکار به‌روزرسانی نمی‌کند.

## محیط‌های دارای پوشه اسکیل

مخزن را با حساب دارای دسترسی دریافت کنید:

```bash
git clone https://github.com/piwoinjast/NobiWriter.git
cd NobiWriter
```

پوشه کامل `skills/nobiwriter` را در محل اسکیل‌های محیط مقصد قرار دهید. `SKILL.md`، `VERSION`، `agents`، `assets`، `references`، `templates`، `scripts` و `tests` باید با ساختار خود حفظ شوند. مسیر نصب و شیوه بارگذاری مجدد را از تنظیمات محیط مقصد تعیین کنید.

نسخه قبلی را پیش از جایگزینی پشتیبان بگیرید. کپی‌کردن پوشه تازه داخل پوشه قدیمی ممکن است یک لایه اضافی بسازد. پوشه نصب باید یک فایل اصلی `SKILL.md` در ریشه خود داشته باشد.

## ساخت بسته قابل انتقال

از ریشه مخزن و با Python 3.12 در محیط مجازی اجرا کنید:

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-dev.txt
python scripts/validate_repository.py
python skills/nobiwriter/tests/check_bundle.py
python -m unittest discover -s skills/nobiwriter/tests -p 'test_*.py' -v
python scripts/package_skill.py
```

خروجی این نسخه `dist/skill.zip` است. ZIP کل مخزن را با بسته نصب اشتباه نگیرید. بسته شامل یک پوشه `nobiwriter` با تمام منابع اجرایی، ابزارها و تست‌های همراه است. فایل محیط مجازی، کش پایتون و پیوند نمادین وارد بسته نمی‌شود.

روند GitHub Actions نیز بسته را با نام آرتیفکت `nobiwriter-skill` می‌سازد. فایل دانلود آرتیفکت، پوشش بیرونی دارد. فایل داخلی `skill.zip` بسته نصب است.

## محیط‌های بدون پشتیبانی اسکیل

محتوای `SKILL.md` را به‌عنوان دستور و منابع مرتبط را به‌عنوان مرجع ارائه کنید. این کار معادل نصب اسکیل نیست. در محیط فاقد اجرای کد، محاسبه و نمایش باید با محدودیت روشن انجام شود. تظاهر به اجرای اسکریپت مجاز نیست.

## بررسی نسخه و رفتار

نسخه در `VERSION` ریشه مخزن و `skills/nobiwriter/VERSION` باید `1.2.0` باشد. قرارداد پاسخ باید تفاوت «فقط یک شعار» با «فقط متن، بدون تحلیل» را رعایت کند.

از `skills/nobiwriter/tests/release-1.2.0-cases.json` برای آزمون رگرسیون استفاده کنید. نتیجه هر اجرا را در قالب ثبت نتیجه همراه با مدل، نسخه و پاسخ کامل ثبت کنید. عبور از آزمون ساختار یا محاسبات، گواه موفقیت رفتار مدل نیست.

## به‌روزرسانی

ابتدا تغییرات محلی را ثبت یا حفظ کنید و سپس `git pull --ff-only` اجرا کنید. اگر شاخه‌ها واگرا شده‌اند، ادغام باید جدا انجام شود. بسته تازه را بسازید و نسخه نصب‌شده را با آن جایگزین کنید. تغییر مخزن به‌تنهایی نصب‌های قبلی را تغییر نمی‌دهد.

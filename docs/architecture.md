# معماری نوبی‌رایتر ۱.۱.۰

بسته نصب در `skills/nobiwriter` قرار دارد. `SKILL.md` نقطه ورود است و با مسیریابی مستقیم، منابع لازم را بارگذاری می‌کند. مستندات استفاده و توسعه بیرون بسته قرار دارند.

| لایه | مسئولیت |
| --- | --- |
| هسته | قواعد الزام‌آور، تشخیص مسیر و شکل پاسخ |
| منابع | هویت، لحن، واژگان، محصول، خلاقیت و ادعا |
| قالب‌ها | دریافت بریف و ورودی مورد نیاز |
| مستندات و نمونه‌ها | آموزش کاربر و نگهداری پروژه |
| قراردادها و ارزیابی | بررسی داده و سنجش رفتار مدل |

قواعد ثابت از داده جاری محصول جدا هستند. مخزن بانک زنده ادعاهای مجاز نیست. نمونه آموزشی شاهد قابلیت محصول نیست. سابقه نسخه‌های پیشین در تاریخچه واحد ریشه حفظ شده است.

# نمونه‌های استفاده

این مثال‌ها برای نشان دادن روش کار نوشته شده‌اند. از آن‌ها نمی‌توان به‌عنوان تایید قابلیت یا مجوز انتشار یک ادعا استفاده کرد.

## ۱. خطای مالی

**درخواست:** برداشت ثبت شده اما نتیجه نهایی و وضعیت کسر مبلغ معلوم نیست. متن «برداشت ناموفق بود، دوباره تلاش کنید» را بازبینی کن.

**نسخه اصلاحی:** وضعیت نهایی برداشت هنوز مشخص نیست.

**منطق:** نامعلوم با ناموفق فرق دارد. تکرار عملیات بدون تایید پیشنهاد نمی‌شود.

## ۲. شعار طلای دیجیتال

**نمونه مرجع تاییدشده کاربر:** طلای همه‌چیزتمام

**چرا مناسب است؟** ترکیبی کوتاه و آشناست و چند مزیت مرتبط با محصول را زیر یک ایده جمع می‌کند. متن مکمل کمپین باید مشخص کند این تعبیر دقیقا به کدام مزیت‌های تاییدشده اشاره دارد. «همه‌چیزتمام» به‌خودی‌خود اجازه وعده سود یا پوشش همه نیازها را نمی‌دهد.

## ۳. سکشن دانلود اپلیکیشن

**درخواست:** برای معرفی اپ، با فرض تایید دسترسی به معاملات رمزارز و خدمات سرمایه‌گذاری، تیتر و توضیح کوتاه بنویس.

**تیتر:** مدیریت دارایی دیجیتال، هر زمان و هر کجا

**توضیح:** دسترسی ساده‌تر به معاملات رمزارز و خدمات سرمایه‌گذاری با اپلیکیشن نوبیتکس

**چرا مناسب است؟** مفهوم مدیریت دارایی را به دو کاربرد مشخص وصل می‌کند. فهرست خدمات باید پیش از انتشار بررسی شود.

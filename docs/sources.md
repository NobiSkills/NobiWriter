# منابع و حدود استفاده

این مخزن قواعد عملیاتی استخراج‌شده از منابع پروژه را نگه می‌دارد. متن کامل پژوهش‌های داخلی، گزارش‌ها و کتاب‌های ثالث همراه بسته نصب توزیع نمی‌شود. [فهرست منابع](source-inventory.json) سابقه دریافت را ثبت می‌کند، نه مجوز بازنشر.

| خانواده منبع | کاربرد | مرجع اجرایی |
| --- | --- | --- |
| تحلیل گفتمان و هویت مطلوب | جهت هویت برند با وزن بالا، بدون تبدیل آرمان به ادعای واقعی | [هویت و لحن](../skills/nobiwriter/references/brand-voice.md) |
| قواعد لحن و نگارش | خطاب، رسم‌الخط و تمایز موقعیت | [هسته](../skills/nobiwriter/SKILL.md) |
| منابع UX و الگوهای نوشتار | وضعیت‌ها و اقدام معتبر | [نوشتار محصول](../skills/nobiwriter/references/ux-and-microcopy-patterns.md) |
| پژوهش رقبا و چارچوب خلاقیت | الهام مفهومی در محدوده واقعیت محصول | [کپی‌رایتینگ](../skills/nobiwriter/references/copywriting-and-landings.md) |
| ادعا و شواهد | دامنه ادعا و نیاز به تایید | [کنترل ادعا](../skills/nobiwriter/references/claims.md) |
| بانک نمونه و بازخورد کاربر | نمونه‌های آموزشی و منطق انتخاب | [نمونه طلا](../skills/nobiwriter/references/gold-campaign-exemplar.md) |

در تعارض اطلاعات، واقعیت تاییدشده و جاری محصول مبنای ادعاست. نمونه رقیب، برداشت تحلیلی و هویت مطلوب برند به‌تنهایی شاهد قابلیت نیستند.

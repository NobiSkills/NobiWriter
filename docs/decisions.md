# تصمیم‌های طراحی
| تصمیم | دلیل |
| --- | --- |
| یک اسکیل و سه مسیر | حفظ هویت مشترک با روش اجرا و معیارهای متفاوت |
| خواندن منابع متناسب با درخواست | جلوگیری از بارگذاری همه پژوهش‌ها در هر کار |
| جداسازی قواعد از داده جاری | به‌روزرسانی هزینه و قابلیت بدون بازنویسی چارچوب |
| بانک ادعا آغازین خالی | الگوهای ادعا، مجوز نوبیتکس نیستند |
| اصلاح نمونه‌های برداشت و اعتبار | جلوگیری از اعلام وضعیت نادرست یا تضمین ضمنی |
| مجوز متن‌باز انتخاب نشده | انتخاب مجوز نباید حقوق شرکت و منابع ثالث را فرض کند |
| حفظ visibility هنگام ادغام | در بررسی 2026-10-24 مخزن عمومی است. این کار visibility را تغییر نمی‌دهد و متن کامل اسناد داخلی را بازنشر نمی‌کند |
| تفکیک ادراک از هویت و حقیقت محصول | گزارش زمستان ۱۴۰۴ مرجع ادراک دوره‌ای است. نقش خردمند تفسیر تحلیلی است و شاهد امنیت یا مصوبه تازه نیست |
| رسم‌الخط خانه با استثنای معنایی | آیین نگارش به قواعد مصرح و ترجیح‌های مشروط تبدیل می‌شود. اصلاح زبان نباید وضعیت مالی را تغییر دهد |
